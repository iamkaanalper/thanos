# Quick Install for Grok TUI users

After cloning this repo:

1. Copy the folders into your ~/.grok/ (or %USERPROFILE%\.grok\ on Windows).
2. Recommended: Use the export script or manually copy the listed portable items.
3. Restart Grok.
4. Try /tesla, /swarm, /implement, /memory.

See README.md (the THANOS-README) for full details, credits to the original @vibeeval/vibecosystem, and the philosophy.

Do not copy sessions/, auth.json, logs/, etc. from your personal .grok.
